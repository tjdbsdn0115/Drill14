# Drill14 — 10마리 새의 왕복 비행

기존 boy의 이동·수면·공 발사 위에 `bird_animation.png`를 사용하는 새 10마리를 추가했습니다.
새는 5열 × 2행 편대를 유지하며 좌우로 왕복하고, boy와 시간 표시 및 빨간 거리 숫자 위를 비행합니다.

## 실행

프로젝트 폴더에서 실행합니다. Python과 SDL 창을 표시할 수 있는 환경이 필요합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

- 왼쪽/오른쪽 화살표: boy 이동
- Space: 기존 상태에 따라 공 발사 또는 잠에서 깨기
- Esc / 창 닫기: 종료
- 새 편대는 별도 조작 없이 계속 비행합니다.

## 비행 논리

| 항목 | 구현 |
| --- | --- |
| 개체 수 | 정확히 10마리, 5열 × 2행 |
| 원본 이미지 | 918 × 506px, 실제 프레임 간격 182 × 170px |
| 애니메이션 | 빈 마지막 칸을 제외한 14개 포즈, 초당 2주기 |
| 이동 속도 | 30km/h → 약 277.78px/s, boy와 같은 월드 축척 |
| 좌우 왕복 | 화면 밖으로 나가지 않으며 초과 이동 거리를 반사 |
| 방향 표현 | 오른쪽은 원본, 왼쪽은 수평 반전 |
| 편대 | 가로 130px, 세로 72px, 모든 새가 함께 방향 전환 |
| 개별 차이 | 새마다 날갯짓 시작 위상을 1.4프레임씩 다르게 설정 |
| 높이 | boy·시간 표시·거리 숫자 중 가장 높은 지점보다 아래쪽 새의 사각 영역 하단이 16px 위 |
| 자원 사용 | 편대 생성 때 PNG 한 번 로드, 10마리가 동일 텍스처 공유 |

정확성은 **제공된 스프라이트의 14개 포즈를 잘림 없이 순서대로 재생하고, FPS와 무관하게 시간을 맞추는 것**을 뜻합니다.
실제 조류의 공기역학을 시뮬레이션하는 방식은 아닙니다. 상세한 좌표 변환, 시간 계산, 왕복 수식과 선택 이유는 [비행 설계 문서](docs/BIRD_FLIGHT.md)에 설명했습니다.

## 검증

```powershell
python -m unittest discover -s tests -v
python tools/check_render.py
```

자동 테스트 13개가 통과했습니다. 30·60·144 FPS의 시간 일치, 양쪽 경계 반사, 긴 프레임 지연,
10마리·편대 간격·화면 경계·숫자 위 높이·모드 종료 정리를 검사합니다.
실제 SDL 렌더 검사로 오른쪽 비행, 왼쪽 비행, 14개 전체 포즈를 출력하고 육안으로 확인했습니다.

검사 이미지는 로컬 `artifacts/flock_right.png`, `artifacts/flock_left.png`, `artifacts/all_14_poses.png`에 생성됩니다.
`artifacts/`와 Python 캐시는 Git에서 제외했습니다.
